# ロボット動画印象評価実験 結果レポート

## 分析の前提

- 対象データ: `データ/きれいデータ.xlsx`
- 回答者数: 126名
- 事前測定:
  - 勇気尺度 6項目
  - CZO尺度 10項目
- 動画視聴後測定:
  - 主観勇気評定 3項目
  - 勇気尺度 6項目
  - CZO尺度 10項目
  - 葛藤尺度 4項目
  - 葛藤確認項目 1項目

本レポートでは、4動画を次の 2 × 2 条件として扱っている。

- 動画1 = 葛藤あり × 行動あり
- 動画2 = 葛藤あり × 行動なし
- 動画3 = 葛藤なし × 行動あり
- 動画4 = 葛藤なし × 行動なし

この対応は、これまでの分析コードでも共通して用いている仮定である。したがって、もし動画条件の割り当てが実際には異なる場合は、要因名の解釈も読み替えが必要になる。

## 仮説

- 仮説1: 行動する方が、観察者の勇気スコアが上がる
- 仮説2: 行動の上、葛藤していた方が、観察者の勇気スコアが上がる

## 1. 尺度の内的一貫性

クロンバックの α 係数は全体として良好であった。

- 事前勇気尺度: α = .908
- 事前CZO尺度: α = .801
- 事後全条件プール 主観勇気評定: α = .938
- 事後全条件プール 勇気尺度: α = .947

## 2. マニプレーションチェック: 葛藤尺度

葛藤尺度はマニプレーションチェックとして、結果レポートの前半で報告する。

### 3.1 2要因分散分析

従属変数は、動画視聴後の葛藤尺度得点である。

- 葛藤の主効果: F(1, 125) = 52.257, p < .001
- 行動の主効果: F(1, 125) = 6.612, p = .011
- 交互作用: F(1, 125) = 1.633, p = .204

対応する効果量は、葛藤の主効果が partial η² = .295、行動の主効果が partial η² = .050、交互作用が partial η² = .013 であった。

条件平均は以下のとおりであった。

- 葛藤あり × 行動あり: 5.089
- 葛藤あり × 行動なし: 5.212
- 葛藤なし × 行動あり: 4.066
- 葛藤なし × 行動なし: 4.353

この結果から、少なくとも本データでは、葛藤あり条件の方が葛藤なし条件よりも高い葛藤評定を受けており、葛藤操作は概ね意図どおり知覚されていたと考えられる。

## 3. 仮説検証1: 勇気尺度

勇気尺度については、事後スコアと、事前スコアからの差分スコアの両方で 2 要因分散分析を行った。

### 4.1 事後スコア

- 葛藤の主効果: F(1, 125) = 0.260, p = .611
- 行動の主効果: F(1, 125) = 2.558, p = .112
- 交互作用: F(1, 125) = 2.591, p = .110

### 4.2 差分スコア

- 葛藤の主効果: F(1, 125) = 0.260, p = .611
- 行動の主効果: F(1, 125) = 2.558, p = .112
- 交互作用: F(1, 125) = 2.591, p = .110

条件平均は以下のとおりであった。

勇気尺度では、行動の主効果も、葛藤との交互作用も有意ではなかった。よって、仮説1および仮説2を、勇気尺度ベースで明確に支持する結果は得られなかった。

## 4. 補足指標: CZO尺度

CZO尺度についても、事後スコアと差分スコアで 2 要因分散分析を行った。

### 5.1 事後スコア

- 葛藤の主効果: F(1, 125) = 0.468, p = .495
- 行動の主効果: F(1, 125) = 4.698, p = .032
- 交互作用: F(1, 125) = 0.132, p = .717

行動の主効果の効果量は partial η² = .036 であった。

### 5.2 差分スコア

- 葛藤の主効果: F(1, 125) = 0.468, p = .495
- 行動の主効果: F(1, 125) = 4.698, p = .032
- 交互作用: F(1, 125) = 0.132, p = .717

差分スコアでも、行動の主効果の効果量は partial η² = .036 であった。

条件平均は以下のとおりであった。

- 葛藤あり × 行動あり: 事後 3.094, 差分 0.076
- 葛藤あり × 行動なし: 事後 3.052, 差分 0.033

- 葛藤なし × 行動なし: 事後 3.057, 差分 0.039

CZO尺度では、行動の主効果のみ有意であり、行動あり条件の方が高かった。したがって、勇気尺度そのものでは有意差が出なかったものの、「コンフォートゾーンの外に出ようとする傾向」に関しては、行動あり動画がより促進的に働いた可能性がある。

## 5. 主観勇気評定 3項目

主観勇気評定は尺度としてではなく、各項目ごとに 2 要因分散分析を行った。

### 6.1 項目1

- 項目文: 「このロボットを見て、自分も挑戦しようと思った。」
- 葛藤の主効果: F(1, 125) = 0.048, p = .826
- 行動の主効果: F(1, 125) = 58.392, p < .001
- 交互作用: F(1, 125) = 11.561, p < .001

効果量は、行動の主効果が partial η² = .318、交互作用が partial η² = .085 であった。

交互作用が有意であったため単純主効果を検討したところ、葛藤あり条件・葛藤なし条件のいずれでも、行動ありの方が行動なしより高かった。効果量は、葛藤あり条件で Cohen's d = 0.520、葛藤なし条件で d = 0.647 であった。また、行動あり条件では葛藤なしの方が高く、行動なし条件では逆に葛藤ありの方が高かったが、これらの効果量はそれぞれ d = -0.246、d = 0.194 であった。

### 6.2 項目2

- 項目文: 「このロボットを見た後に、難しいことにも一歩踏み出せそうだと感じた。」
- 葛藤の主効果: F(1, 125) = 2.448, p = .120
- 行動の主効果: F(1, 125) = 53.050, p < .001
- 交互作用: F(1, 125) = 3.792, p = .054

行動の主効果の効果量は partial η² = .298 であった。

行動の主効果は有意であり、交互作用は有意水準 .05 では有意ではなかった。

- 項目文: 「このロボットから勇気をもらったと感じた。」

- 行動の主効果: F(1, 125) = 86.035, p < .001
- 交互作用: F(1, 125) = 3.995, p = .048

効果量は、行動の主効果が partial η² = .408、交互作用が partial η² = .031 であった。

交互作用が有意であったため単純主効果を検討したところ、葛藤あり条件・葛藤なし条件のいずれでも、行動ありの方が行動なしより高かった。効果量は、葛藤あり条件で Cohen's d = 0.658、葛藤なし条件で d = 0.762 であった。一方で、葛藤ありと葛藤なしの差は有意ではなく、効果量も小さかった（行動あり条件で d = -0.119、行動なし条件で d = 0.134）。

## 6. 総合的な考察

本研究では、

- 仮説1: 行動する方が、観察者の勇気スコアが上がる
- 仮説2: 行動の上、葛藤していた方が、観察者の勇気スコアが上がる

を掲げていた。

まず、マニプレーションチェックとしての葛藤尺度では、葛藤あり条件が葛藤なし条件より明確に高く、しかもその効果量は partial η² = .295 と比較的大きかった。したがって、操作は概ね成立していたと考えられ、「葛藤が知覚されていなかったために仮説が検証できなかった」という解釈は取りにくい。

そのうえで主要な結果を見ると、仮説1は尺度によって支持の程度が異なった。勇気尺度では、事後スコア・差分スコアともに行動の主効果は有意ではなく、観察者の一般的な勇気傾向そのものが短時間の動画視聴だけで明確に上昇したとは言いにくい。一方、CZO尺度では行動の主効果が有意であり、効果量は partial η² = .036 と大きくはないが、一定の差は確認された。さらに主観勇気評定の 3項目では一貫して行動の主効果が認められ、効果量も項目1で partial η² = .318、項目2で .298、項目3で .408 と比較的大きかった。つまり、観察者は「勇気をもらった」「自分も挑戦しようと思った」と主観的には強く反応しているが、それが直ちにより安定的な自己特性としての勇気尺度にまで反映されたわけではない可能性が高い。

仮説2については、全体として強い支持は得られなかった。勇気尺度でも CZO尺度でも、葛藤 × 行動の交互作用は有意ではなかった。主観勇気評定では項目1と項目3で交互作用が見られ、効果量はそれぞれ partial η² = .085、.031 であったものの、そのパターンは「葛藤している上で行動していた方が一貫して最も高い」という単純な形ではなかった。むしろ、主観的な勇気喚起には、葛藤の有無よりも「実際に行動していること」そのものがより強い影響を持っていたと解釈する方が自然である。

この結果から、観察者にとって重要なのは、ロボットが葛藤していること自体よりも、最終的に行動に踏み出している姿を見せることだと考えられる。葛藤はマニプレーションとしては知覚され、動画の印象形成には関わっているものの、観察者の勇気や挑戦志向を高める中心的な要因は、少なくとも本データでは「行動の提示」であった可能性が高い。

一方で、主観勇気評定では交互作用が一部の項目で生じており、葛藤の役割が完全に無関係だったとは言い切れない。葛藤は、観察者がロボットをより人間的、あるいは心理的に共感しやすい存在として捉えるきっかけにはなっているかもしれない。ただし、その効果は安定した尺度得点全体にまで広く及ぶほど強くはなく、項目水準の反応にとどまっている可能性がある。

まとめると、本研究の結果は、

- 「行動あり」は主観勇気評定およびCZO尺度では有効だった
- しかし勇気尺度そのものの上昇までは明確には示されなかった
- 「葛藤している上で行動していること」の付加的優位性は限定的だった

ことを示している。

したがって、研究全体としては、仮説1は主観評価とCZO尺度の範囲では一定程度支持され、仮説2は限定的な支持にとどまったと結論づけるのが妥当である。
